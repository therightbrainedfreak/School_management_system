# School ERP System

## Description
A comprehensive Enterprise Resource Planning (ERP) system tailored for educational institutions to streamline school management processes (based on Indian schools).

## Features
- Student enrollment and management
- Teacher and staff administration
- Attendance tracking
- Grade and performance reporting
- Fee management
- Timetable scheduling
- User role-based access control

## ENV variables
- PORT for backend
- MONGO_URI
- MAIL_USER nodemailer app email
- MAIL_PASS nodemailer app password
- JWT_SECRET secret string for jwt signing

## Technologies Used
- Frontend: HTML, CSS, JavaScript (e.g., React)
- Backend: Node.js, Express
- Database: MongoDB
